##> To start the application locally you need to have already installed the following in your system(Linux):
    1. Python(3.10+) -> Linux systems already comes with pre-installed python, check (python3 --version) 
    2. Node(24.14.0 LTS) -> https://nodejs.org/en/download
    3. Redis -> https://redis.io/docs/latest/operate/oss_and_stack/install/install-stack/apt/
    4. Docker -> https://docs.docker.com/desktop/setup/install/linux/ubuntu/

#> Install Packages for Backend server (Linux)
    python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt

#> Install Packages for Frontend server (Linux)
    cd app_frontend_VUE && npm install

#> Check Docker service is active or not and the current running containers
    sudo docker ps

#> Start Docker Service and Socket
    sudo systemctl start docker.service && sudo systemctl start docker.socket

#> To run the application backend server (Linux)
    source .venv/bin/activate && python3 app.py

#> To run the application frontend server (Linux)
    cd app_frontend_VUE && npm run dev 

#> Start Redis server (Linux)
    sudo systemctl start redis-server

#> Check redis server is active or not (Linux)
    redis-cli ping

#> Run the test smtp server with ui (mailhog) 
    docker run -d -p 1025:1025 -p 8025:8025 mailhog/mailhog

**Note: 
1. When the application runs for the first time it will create the frontend distribution by its own using python subprocess to run 'npm' build command. The compiled frontend dist will be then served from the same backend server.
2. We are using 'mailhog' a testing smtp server and for that we need docker services, else docker has not been used anywhere in the project.

@> Ports:

http://localhost:5080/ - flask backend
http://localhost:6379/ - redis server
http://localhost:5173/ - vue frontend 
http://localhost:1025/ - mailhog smtp server
http://localhost:8025/ - mailhog email ui
